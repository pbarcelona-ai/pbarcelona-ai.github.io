Streaming lens-distortion correction

A compact, testable demo of calibrated image remapping in RTL.

The design buffers an RGB frame, maps each output pixel to a source coordinate, and reconstructs the output with bilinear interpolation. It supports radial and tangential distortion parameters and uses AXI4-Stream video I/O with AXI4-Lite configuration.

How the demo works

What is included

Correction pipeline

  • Radial coefficients k1, k2, and k3, plus tangential coefficients p1 and p2.
  • Per-pixel coordinate generation followed by four-tap bilinear interpolation.
  • Clamp-to-edge sampling for coordinates beyond the frame.
  • 31-cycle request-to-pixel latency; a fully pipelined datapath accepts one pixel request per clock.

Interfaces and verification

  • AXI4-Stream RGB888 input and output, with frame and line markers.
  • AXI4-Lite register interface for frame geometry and calibration parameters.
  • SystemVerilog testbenches run with Icarus Verilog and generate synthetic test charts.
  • The barrel-distortion regression checks output against a golden model and measures image-error improvement.
Measured simulation example: for one barrel-distortion test, mean absolute error fell from 68.4 on the warped image to 34.4 after correction. This is a testbench result, not a hardware performance guarantee.

A deliberately limited build

This page describes the compact demonstration edition, not a general-purpose video pipeline. Other versions are available with expanded capabilities, including additional correction models, interpolation options, and larger-frame workflows.

  • The frame buffer is internal memory only and sized for 128 × 128 pixels; there is no external-memory path.
  • Frames are processed sequentially. The next input frame waits until the previous output completes.
  • Output backpressure is not supported; keep m_axis_tready asserted.
  • Bilinear interpolation is the only mode in this demo. Its full image regression exercises barrel distortion.
  • Test input is generated by the testbench; this demo does not load user-supplied image files.
  • Frame dimensions are not checked against the buffer limit in RTL. Keep configured dimensions at or below 128 × 128.

Timing figures are synthesis-netlist estimates, not vendor place-and-route timing sign-off.
